# PALINDROME

This is a script checking if a given a string of random characters could be palindrome.

## Personal comment
I choose to solve it with recursion because I find it more interesting and challening.

Any recommendations are welcomed.

## Requirements
You should have node installed.

## Usage
1. Clone the repo.
2. @line 49 you can write the string of characters you wish. (stringToBeTested is the variable we use)
3. Go through your terminal in project folder.
4. Run node canBePalindrome.js.
5. See if it is a palindrome or not.
